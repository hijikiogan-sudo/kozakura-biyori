# こざボタびより v1.2.0

愛鳥との毎日を、写真と記録で残す無料のPWAです。

## 名前・並び順・インコのイラスト

旧「コザクラ日和」から「こざボタびより」に名称を変更しました。公開URL、IndexedDB名 `kozakura-biyori-local-v1`、バックアップの識別子 `kozakura-biyori` は引き継ぎます。既にiPhoneのホーム画面へ追加したアプリ名は自動で変わらない場合があります。名前を変えるためにサイトデータを削除しないでください。

「行動の記録 → 並べ替え」で、12項目を「上へ・下へ」で移動し、「順番を保存」で確定します。変更の取り消しや元の順番への復帰もできます。順番を変えても行動名と記録内容は変わりません。

「行動の記録 → インコのイラストを選ぶ」または「メニュー → インコのイラスト」で、コザクラインコ／ボタンインコを各6色から選べます。行動のイラスト、アプリ内の鳥のアイコン、写真未設定時の表紙・タイマーに反映します。ホーム画面にインストールしたアプリアイコンをユーザー別に切り替える機能ではありません。選んだ写真は維持します。並び順・イラスト設定は端末内とv2バックアップに保存し、旧バックアップには初期設定を補います。

## 行動の記録

行動をイラスト付きの12項目からワンタップで記録できます。従来の9項目に「ご飯を食べる」「水を飲む」「くちばしギョリギョリ」を追加しました。食べる・飲む行動は、「ご飯替え」「水替え」のお世話記録とは別に保存します。既存の行動名・記録・バックアップは引き継ぎます。

## ホーム写真のカスタマイズ

ホーム写真の編集ボタン、または「メニュー → プロフィール」から、「いつもの形」「横長・コンパクト」「縦長・大きめ」のレイアウトを選べます。プレビューを見ながら、写真の拡大率（1〜3倍）と左右・上下の位置を調整できます。プレビュー上の写真をドラッグして位置を動かすこともできます。右側の吹き出しは40文字までのフリーコメント（改行可）に変更でき、空欄で非表示になります。

「プロフィールを保存」で写真・配置・コメントをまとめて端末内へ保存します。閉じると編集を取り消します。元画像・アルバム内の写真を切り抜いたり上書きしたりしません。既存プロフィールには従来の表示に合わせた初期設定を補い、v1・v2バックアップの復元も維持します。新しい表示設定もv2バックアップに含まれます。

## 放鳥タイマー

「時間を計る」で0からの経過時間、「カウントダウン」で設定時間からの残り時間を表示します。15分・30分・60分のボタン、または1〜1,440分の自由入力で設定できます。開始したタイマーは再読み込み後も引き継ぎます。旧版の計測中タイマーも経過時間の計測として継続します。

残り時間が0になると画面で知らせます。自動では終了せず、「放鳥を終了」を押した時点までの実際の経過時間を記録します。画面を表示している間は終了音を鳴らし、タイマー以外の画面でも終了時に表示で知らせます。「終了音を試す」で端末の音量を確認してください。再読み込み後は、音の再生を有効にするためボタンを押し直す場合があります。画面を閉じている間の音・通知をPWAだけで保証することはできません。開き直すと残り時間を更新します。

カウントダウン開始後の「終了のお知らせ用ファイルを書き出す」で、その回の終了予定時刻に一度だけ通知する .ics を生成します。標準カレンダーに予定を追加し、予定の通知とiPhoneの通知許可・音量・消音・集中モードを確認してください。ファイルを保存しただけでは通知は有効になりません。iPhoneだけで取り込めない場合はMacのカレンダーから同じiCloudカレンダーへ追加してください。短時間のタイマーですぐに音が必要なら、iPhoneの「時計 → タイマー」に残り時間を設定する方法を使ってください。

予定には写真や飼育記録を含めず、アプリから外部配信サーバーを使いません。追加した予定の同期は利用者のカレンダー設定に従います。タイマーを取り消す・早めに終了する場合、カレンダー側の予定も手動で削除してください。アプリから追加完了・通知許可を確認したり、カレンダーの予定を自動削除したりはできません。繰り返し書き出しても同じタイマーには同じUIDを使いますが、取り込み先によっては予定が重複するため重ねて追加しないでください。お世話のお知らせも引き続き標準カレンダー用の予定ファイルを使います。

## v1.1.0の主な機能

- クリーム・淡い緑・ピンクを基調にした画面。大きな愛鳥画像、健康チェック、放鳥ボタン、イラスト付き行動記録。
- 掃除・水替え・ご飯替えの実施時刻・回数・メモの記録、編集、カレンダー表示。
- 専用の放鳥タイマー、体重のグラフ・一覧・メモ、9種類の行動ワンタップ記録。
- 月送りカレンダー、写真・動画・お気に入りのアルバム、通院・産卵・発情記録。
- 7日・30日・3か月・1年の健康グラフ（体重／放鳥／食欲／フン／活動量）。未記録日は補完せず、健康の「気になる」は数値に置き換えない。
- お迎え日から一緒に過ごした日数を表示。
- 標準カレンダーで通知するための .ics ファイルを書き出し。

## 保存・互換性

写真・動画・プロフィール・飼育記録は端末内のIndexedDBに保存します。外部サーバーやGitHubへの送信・共有・同期はありません。データベース名は旧版と同じです。新版に更新しても既存記録を引き継ぎ、v1バックアップを復元できます。新版の書き出しはバックアップ形式v2です。v2は旧アプリでは復元できないため、更新前のバックアップも保管してください。

初期プロフィールに私有写真は使用しません。実測でない記録は初期投入しません。イラストとアイコンはこのアプリ用のオリジナルです。参考画像そのものや写真は同梱していません。

写真・動画は合計100件、記録50,000件、全体約38MBまで。画像は長辺1024pxに縮小してJPEG保存し、位置情報などを引き継ぎません。動画は1本8MB以下のMP4/MOV/WebMを元のまま保存し、端末・ブラウザが対応するコーデックで再生します。動画には位置情報等のメタデータが含まれる可能性があります。バックアップを他人に渡す前に確認してください。

プライベートブラウズを避け、ホーム画面アプリに利用場所を統一してください。Webサイトデータ削除、端末故障・交換、容量不足、OSの整理などでデータが失われる場合があります。「メニュー → データのバックアップ」から定期保存し、「ファイル」アプリへの保存完了を確認してください。

## iPhoneでの使い方

Safariで公開URLを開き、共有 → ホーム画面に追加。ホーム画面から起動し「オフライン準備完了」を確認します。初回はオンライン接続が必要です。プロフィールの写真を各自の写真ライブラリから設定してください。

公開先の予定URL: https://hijikiogan-sudo.github.io/kozakura-biyori/

## アプリを閉じているときのお世話通知

外部の配信サーバーは使いません。アプリの「メニュー → お知らせ設定」でお世話ごとに有効・時刻・繰り返し間隔を設定し、「カレンダー用ファイルを書き出す」を実行します。

生成した .ics を標準カレンダーへ読み込むと、指定時刻のアラームを含む繰り返し予定になります。iPhoneで読み込み操作ができない場合はMacのカレンダーで読み込み、iPhoneと同じiCloudカレンダーへ追加してください。予定の通知とiPhoneの通知許可を確認する必要があります。ファイルの書き出しだけでは通知は有効になりません。追加済みかどうかをアプリから確認することはできません。

通知時刻の変更・停止は、標準カレンダー側の既存予定も変更・削除してください。お世話をアプリに記録しても、カレンダーの予定・通知は自動では取り消されません。標準カレンダーの同期は各利用者のカレンダー設定に従います。

## 配備・更新

ビルド不要の静的ファイル構成です。専用のGitHub Pagesリポジトリのルートに一式を置きます。sw.js・app.js・index.htmlの表示バージョンとキャッシュ名をそろえています。model.js・art.svgも配備してください。

オンラインで開いたときに更新を取得します。新版の準備後、アプリを閉じて開き直すと新しいキャッシュを使います。更新してもIndexedDBの記録は消しません。他アプリのキャッシュを削除しません。

広告・解析・課金APIは使用しません。日々の観察を記録するアプリであり、診断や適正体重の判定は行いません。

## 開発時の確認

静的サーバーは `python3 -m http.server 8000 --bind 127.0.0.1` で起動できます。

行動記録・ホーム写真・放鳥タイマーのブラウザ回帰テストは、Pythonの `playwright` とChromiumが必要です。準備済みのクラウド環境では、リポジトリ直下で `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v` を実行します。テスト用HTTPサーバーと独立したブラウザ保存領域を使い、新しい行動の保存・編集・旧行動の保持、ホーム写真の選択・表示範囲・ドラッグ調整・コメント・保存と取り消し・バックアップ復元・オフライン表示、カウントアップ、時間指定・入力検証、再読み込み、時間切れ後の実時間記録、旧タイマー、取り消し、オフライン動作を確認します。iPhone実機の動作・通知確認は別途必要です。

表示設定のデータ互換性・バックアップ、および終了通知用の予定時刻・一回限りのアラーム・既存のお世話通知は `node --test tests/*.cjs` で確認します。

インコの配色を変更・追加した場合は、`model.js` の `BIRD_APPEARANCES` を更新して `python3 scripts/generate_bird_art.py` を実行し、生成した `art.svg` と `birds/` のSVGを一緒に配備します。新しい配色ファイルは `sw.js` のオフライン対象にも追加してください。
