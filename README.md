# コザクラ日和

愛鳥との毎日をやさしく記録する、無料の静的PWAです。

公開URL: https://hijikiogan-sudo.github.io/kozakura-biyori/

## できること

- 愛鳥の名前・性別・推定年齢・プロフィール写真の変更
- 健康（食欲・フン・活動量）、実測体重、放鳥、産卵、行動の記録
- 放鳥タイマー、直近30件の体重グラフ、記録カレンダー
- 端末内の写真アルバム、写真の変更・削除
- 写真を含むJSONバックアップの書き出し・復元
- ホーム画面追加とオフライン起動

## iPhoneで使う

1. Safariで公開URLを開きます。
2. 共有メニュー → 「ホーム画面に追加」。表示される場合は「Webアプリとして開く」をオンにします。
3. ホーム画面から起動し、「オフライン準備完了」の表示を確認します。
4. プロフィールを編集し、自分の写真ライブラリから愛鳥の画像を選びます。
5. 機内モードでも起動・記録・再起動後の保存ができることを実機で確認します。

ホーム画面追加の操作はiOSのバージョンで異なる場合があります。

## 保存とプライバシー

写真と記録は、その端末・そのブラウザのIndexedDBだけに保存します。アカウント登録や同期機能はありません。別の人が同じURLを開いても、その人の空の保存領域から始まります。同じ端末・同じブラウザを共用すると記録も共用されます。

ユーザーが選んだ写真は、ブラウザ内で長辺1024pxまで縮小してJPEGとして保存します。元の写真は変更せず、位置情報等のメタデータも引き継ぎません。写真や飼育記録をサーバー・GitHubにアップロードするコード、広告、アクセス解析、外部フォント、課金APIはありません。GitHub Pages側にはアクセスに伴う通信情報が残る場合があります。

プロフィールと記録は空から始まり、私有写真や実測でない体重等は同梱しません。初期イラスト・アイコンはこのアプリ用に作成したものです。利用者は自分が利用する権利のある画像を選んでください。

保存上限は写真100枚、記録50,000件、データ全体約38MBです。実際にはOSの空き容量により、それ以前に保存できない場合があります。エラー時は保存成功を表示しません。

Safariの画面とホーム画面アプリ、別のブラウザでは保存領域が異なる場合があります。継続利用はホーム画面アプリに統一してください。Webサイトデータの削除、端末交換・故障、容量不足、OSの整理等により記録を失う場合があります。プライベートブラウズを避け、定期的に「設定」からバックアップし、「ファイル」アプリに保存されたことを確認してください。

復元は既存データを置き換えます。内容を検証した後、確認画面を表示します。別の端末へ移行するとき、実行中の放鳥タイマーは引き継ぎません。

## 放鳥タイマー

バックグラウンドで実行し続ける方式ではなく、開始時刻と現在時刻の差から計算します。画面を閉じたり端末をスリープしている時間も含みます。アラーム・通知はありません。終了忘れや端末時計の変更があった場合は取り消して実際の時間を手入力してください。7日を超えたタイマーは手入力を案内します。

## 配備・更新

ビルド不要。独立した公開リポジトリのmainブランチ直下にこのフォルダのファイルを配置し、Settings → Pages → Deploy from a branch → main / (root) で配備します。GitHub Freeの公開リポジトリに対応する静的構成です。他のアプリのリポジトリは使用しません。

更新時はsw.jsのキャッシュバージョンとapp.jsの準備確認用キャッシュ名、index.htmlの表示バージョンをそろえて変更してください。公開後、オンラインで開き直して更新します。キャッシュの削除はこのアプリ名の古いキャッシュだけに限定しています。

## 確認範囲

このアプリは観察の記録用で、診断や目標体重の提案はしません。

自動確認: バックアップの形式・日付・数値・画像URL・重複IDの検査、外部送信コードの不在、オフライン時の起動・アセット応答、他アプリの領域を処理しないこと。

画面確認と実機確認の詳細は、この作業の検証結果レポートを参照してください。iPhone実機でのSafari操作は、実機を接続して確認するまで未検証です。
