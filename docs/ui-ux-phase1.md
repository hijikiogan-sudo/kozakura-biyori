## 健康入力の安全な仕様

Phase 1は新規の3項目を「選んでください（未選択）」にし、明示的に選ぶまで保存しない。表示だけの空の選択肢であり、保存する値は従来の `いつもどおり / 少なめ / 多め / 気になる` のまま。当日の健康チェックから既存記録を編集できるようにする。既存記録・旧バックアップ・グラフの意味を保つ。未確認のままの保存は今回追加しない。

後続の選択肢案: 食欲・活動量に保存値「未確認」、フンに「いつもと違う」「未確認」を追加し、フンの過去の「少なめ」「多め」「気になる」も編集時に選べるようにする。未確認は数値にせずグラフの欠測扱い、「いつもと違う」は従来の「気になる」と同様に非数値の注意点として表示する案。旧アプリは新しい値のバックアップを拒否するため、互換性の方針とグラフの表示を確認してから別実装する。既存値を一括変換する案は採らない。

## Phase 1の安全策

- 1タップ追加は保存トランザクション内でも実施済み・予定枠を確認する。
- 「もう1回記録」は別操作で入力画面を開く。既存の編集・削除は残す。
- 取り消しは追加したIDと内容を照合し、その1件だけを削除する。別タブで編集された記録は消さない。再読込後に古い取り消し操作を復元しない。
- 二重送信を防ぎ、保存中は「保存中…」を表示する。アプリ内の閉じる操作とEscは保存完了まで待たせる。
- ブラウザ終了を抑止できる場合は保存中に確認を出す。ただしiOSによる強制終了は保証できない。IndexedDBの原子的保存を維持する。
- タイマーの終了・取消は確認を維持し、確認中に別タブで変わったタイマーを操作しない。
- OS通知やバックグラウンド音が予約されたと誤認する表示は追加しない。
