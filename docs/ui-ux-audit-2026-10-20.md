## 3. 健康の選択肢に関する安全な提案（未実装）

現行の保存値は食欲・フン・活動量とも `いつもどおり / 少なめ / 多め / 気になる`。新規時だけ空の選択肢を表示し、空の値では保存しない。グラフは少なめ=1・いつもどおり=2・多め=3、気になるは非数値の注意として扱う。

当面はこの方式を維持する案が最も互換性への影響が小さい。未確認であることを記録する新しい保存値は導入しないため、「未選択のまま一部だけ保存する」操作はできない。

将来、フンに `いつもと違う / 未確認` を追加する場合は、表示・入力・検証・一覧・グラフ・バックアップを一緒に対応する必要がある。未確認は正常値にせず欠測、いつもと違うは非数値の注意として表示する案。過去の少なめ・多め・気になるはそのまま編集可能にする。過去データを一括変換しない。

旧版アプリはこれらの新しい値を含むバックアップを受け入れられない。実装前に、この制約・表示例・バックアップ形式の扱いを提示して仕様を確認する。新しい値を従来の正常値に置き換えて旧版へ渡す案は採用しない。
