# ホームの操作選択とお世話の最終実施日時

2026年10月20日、main `2f75182`（v1.9.0）を確認し、`codex/home-shortcuts-care`で実装。公開版はv1.10.0。

## 現状と変更

従来はホームの4つの操作が固定で、お世話は当日の実施状況だけが見えた。

- 「よく使う操作」の変更画面を追加。ホームの「変更する」とメニューから開く。
- 12種類の操作から1〜4つを表示順に選ぶ。重複・全て空欄は保存しない。空欄の枠は詰めて表示する。
- 初期値は体重・行動・写真・カレンダー。初期値に戻す操作も明示的に保存するまで反映しない。
- 健康は今日の入力/編集、メモは今日の入力、かじり跡は専用アルバムへ直接進む。
- 写真下の放鳥スタート、写真サイズ/表示範囲、5つの下部ナビは維持。
- 今日のお世話に、ご飯替え・水替え・掃除の最終実施を表示。予定設定に関係なく表示する。
- 実施日・実施時刻で並べ、同一時刻は作成日時で順序を決める。旧記録で時刻がない場合は従来と同じ作成日時の端末ローカル時刻を使う。未来日時は対象外。
- 今日・昨日・年/月/日と時刻を表示。未記録も明記。記録操作で即時再描画し、既存の30秒更新・画面復帰でも更新する。

## データへの影響

`settings.homeShortcuts`だけを任意設定として追加。既存データにない場合やローカル値が不正な場合は従来の4つを使う。インポートでは不正な指定を拒否し、v1/v2の両方で選択を復元する。以前のバックアップも読み込める。

IndexedDBの名前 `kozakura-biyori-local-v1` とバージョン1、アプリ識別子、公開URL、記録/写真/動画の構造・上限、バックアップのバージョンを維持。移行・既存記録の書換えはしない。最終実施日時は保存済み記録から計算し、別の履歴を作らない。外部送信や依存ライブラリは追加しない。

- `app.js`: ホーム設定画面、選択した操作の導線、最終実施日時表示。
- `style.css`: 既存配色の設定/日時表示と折り返し。
- `index.html` / `sw.js`: v1.10.0の表示・オフラインキャッシュ更新。
- `README.md` / 本書: 仕様と確認事項。

- `tests/test_timer.py`: 既存の日計テストを午前の固定時刻にする。改修前にも実行時刻が23時台だと16分の進行で日付をまたぎ、同日合計の期待値と不一致になった。日付またぎの製品動作は変更せず、別の既存テストで維持を確認する。

## 検証

新規Node 3件で旧データの初期値、v1/v2復元、重複・不正・範囲外指定を確認。新規Playwright 5件で選択/順番/取消/初期化、全操作の導線、実施日順/旧時刻/予定ありの表示、追加/取り消し/編集/削除、オフライン再起動と実際の復元、320/390/402pxと文字100/200%の幅・タップ領域を確認する。使うのは分離したテスト用DBと合成記録だけ。

最終確認ではNode 37件・Python/Playwright 77件、合計114件が全て通過した。ホームと設定画面をChromiumで目視し、設定画面についても320/402px・文字100/200%で横はみ出しがないこととselectの高さ44px以上を確認した。

iPhone実機は未確認。Safari/ホーム画面PWAで更新後、操作選択、文字の折り返し、最後に実施した時刻の一致、記録取り消し、設定の再起動後の保持を確認する。背景通知方式、健康の保存値、複数羽管理、App Store公開は変更しない。
